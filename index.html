Why I Created It

Security learning should be easier to enter.

I created Axe-cess to explore ways of making cybersecurity more fun, approachable, and easy to understand. Access management can sound abstract or intimidating, but it affects real people and real organizations every day.

The game uses a familiar arcade pattern to make the topic feel less like a lecture and more like a challenge. Instead of memorizing policy language, players practice judgment: which access attempts feel normal, and which ones deserve immediate attention?

What Players Learn

Edutainment for access management basics.

01

Risk signals

Players learn to notice suspicious clues such as privilege escalation, off-hours access, token creation, unusual device activity, and sensitive data exports.

02

Decision speed

The timer creates urgency, helping people practice fast triage while still reading carefully before acting.

03

False positives

Safe doors are mixed in so players learn that access management is not only about blocking everything. Good security requires judgment.
